# LyricDrop for Windows 1.0.0

首个 Windows 公开版本。

## 功能

- 播放本地音频以及 HTTP/HTTPS 音频地址
- 自动加载同名 LRC，并支持常见中文编码
- 桌面歌词、多行平滑显示、点击穿透锁定
- 多种整行渐变主题、字体、字号、阴影和窗口宽度设置
- 播放、暂停、停止、前后跳转、实时拖动进度、倍速和音量控制
- 歌词时间偏移和歌词行双击跳转
- 系统托盘常驻并恢复上次打开的文件

## 系统要求

- Windows 10 1903 或更高版本
- x64 处理器

本发布包包含 .NET 运行时，无需另行安装 .NET。

## 已知限制

- OGG 播放依赖系统安装相应的媒体扩展。
- 暂不支持全局媒体快捷键、播放列表和登录时自动启动。
